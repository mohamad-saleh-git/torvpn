# torvpn

TorVPN is a simple and secure way to access the Tor network.

#command

python3 torvpn.py setup
python3 torvpn.py connect
python3 torvpn.py connect -m obfs4
python3 torvpn.py connect -m direct  
python3 torvpn.py disconnect  
python3 torvpn.py status
python3 torvpn.py test-bridges FILE 

#setup
1. you need mac 
2. git clone https://github.com/mohamad-saleh-git/torvpn
3. run python3 torvpn.py setup
